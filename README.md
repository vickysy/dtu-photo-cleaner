# 轻了相册 · AI 相册整理（安卓）

> 清了没？原名“D图”，v2.7 起改名“轻了相册”。

手机 512G 还是满？轻了相册把你的相册过一遍：连拍里挑最好的一张，同一个地方拍了几十张只留几张精华，找出拍糊的、误拍的、过期的截图，把 4K 视频压成 1080p……你只需要扫一眼，点确认。

它不只是删。截图和照片会按里面的字自动分好类：证件、聊天记录、文章与文件、票据、订单……平时找身份证、翻聊天截图，打开它点一下就到；选几张拼成长图，直接发给朋友或笔记 App。

**所有分析都在手机上完成。轻了相册没有联网权限，照片不会离开你的手机。**

> 作者木妈是 AI 教育实践者，习惯从自己的真实问题出发，用 AI 把想法变成作品。手机总是满，于是用 AI（Claude Code）边聊边做，一天做出第一版，又在朋友们的反馈里一路改到现在。

- 免费，不用注册，没有广告

## 能做什么

| 功能 | 轻了相册帮你做什么 | 你要做什么 |
| --- | --- | --- |
| **刚拍的** | 拍完马上给最近拍的照片打分；低分、拍糊、连拍里差的已经勾好 | 长按桌面图标选“看刚拍的”，扫一眼点删除 |
| **相似照片** | 连拍、重复保存的照片分组，每组挑一张最好的（看清晰度、曝光、有没有人闭眼、构图美感） | 一页滑下来，点照片切换删/留 |
| **场景精选** | 同一个地方连续拍了几十张，每个场景挑 3–5 张不重复的精华 | 看一眼精华对不对，点这个场景的“删除” |
| **废片** | 明显拍糊、太暗、过曝、误拍的已经勾好；拿不准的只标“可能模糊” | 扫一眼 |
| **截图分类** | 识别截图里的字：取件码、验证码、付款码这类用完就没用的，过几天自动勾上；证件永远不勾 | 扫一眼 |
| **分类相册** | 截图和照片按里面的字分好类：证件、聊天记录、文章与文件、票据行程、订单物流；首页一排入口，点开就是一个相册（首页只显示图标，不露出证件照片） | 平时当相册用：看大图、分享、删除 |
| **拼长图** | 在任何一类里多选几张（按住横着一划能连续选），按拍摄时间拼成一张长图，存进“轻了笔记”并直接弹出分享 | 发给朋友、微信、Get笔记 |
| **好评** | 聊天记录里学员、客户夸你的截图，设为好评后单独收进“好评”相册，永远不会被建议删除 | 发朋友圈前拼一张长图 |
| **截图笔记** | 看直播、上网课连续截的一串图，一键拼成长图、整理出文字 | 分享到笔记 App、微信 |
| **压缩视频** | 4K 视频转成 1080p H.265，体积约为原来的 1/5，拍摄时间、地点、方向不变 | 压完对比看，满意了再删原视频 |
| **视频场景精选** | 同一个地方拍了好几段，推荐留 2–4 段 | 长按播放看一眼再删 |
| **可删的视频** | 抽帧检查：黑屏、误录、重复保存、不到 3 秒的已经勾好 | 扫一眼 |
| **美感排行** | 用离线美感模型给照片打 1–10 分，从低到高排 | 自己挑 |
| **App 存的图** | 微信、小红书等存进相册的图按来源分好 | 自己挑 |

还有一些贴心的小设计：
- 删除一组、一个场景只删眼前这一组；一次删很多组时会先弹窗说清楚删多少张。
- 你在相似照片里改了推荐，会记下你更看重“好看”还是“清楚”，越用越懂你。
- 充电时在后台分析新拍的照片；每月提醒一次能腾出多少空间（都可以在设置里关）。
- 设置里能把安装包直接发给朋友。

## 名字和设计

**为什么叫“轻了”**

“清了”和“轻了”读音一样（qīng le），意思一前一后：

- **清了**是动作：相册清了。
- **轻了**是感受：手机轻了，心也轻了。

所以 App 名字用“轻了”，提醒用“清了没？”，像“吃了没？”那样的日常问候。每月提醒写“这个月，相册清了没？”；删完的那一刻显示“相册轻了 3.2 GB”。连起来就是：清了没？→ AI 替你挑好 → 你点一下确认 → 轻了。

名字里特意不用“清理”两个字：它不想做又一个“清理大师”，而是帮你挑出值得留的那几张。原名“D图”的 D 是 Delete。

**图标**

<img src="docs/logo.svg" width="64" align="right" alt="">

3×3 的照片格子，右上角那一张被挑了出来：绿底，一颗黄星。一堆照片里，留下最好的那张。拍很多，留几张。

**配色**

白底，让界面本身就“轻”；绿色是作者书封面上的品牌绿（`#2FC4A0`），用在按钮和勾选上；黄色（`#F6CC45`）只用在重点上，像荧光笔划过一样，比如“相册还能轻 45 GB”下面那一道。

## 安装

1. 用手机浏览器打开 [官网](https://qingle.nativeailab.cn) 或 [Releases](../../releases/latest) 下载 APK，在手机上点开安装。微信里打不开下载的话，点右上角选“在浏览器打开”。
2. 手机提示“未知来源”或“外部来源应用”时，允许这一次安装。华为、荣耀手机如果开着“纯净模式”，安装被拦住时先暂时关掉。
3. 用微信发安装包时，对方收到的文件名结尾可能多出“.1”（比如 `xxx.apk.1`），在文件管理里把 `.1` 删掉再安装。
4. 打开后允许访问照片时选“全部允许”。第一次分析几千张两三分钟、几万张十几分钟，建议边充电边等。

能不能装：
- 安卓 11 及以上：小米、OPPO、vivo、荣耀、一加等都可以
- 华为鸿蒙 4 及以前可以；鸿蒙 5 及以上（纯血鸿蒙）不行
- iPhone：有原生的 iPhone 版，还在测试，目前只能自己用 Xcode 装（见下面“iPhone 版（预览）”）
- 目前只在荣耀 MagicOS 10（安卓 16）真机上完整测过，其他手机遇到问题欢迎反馈

升级：下载新版本直接覆盖安装，分析结果和设置都会保留。

## iPhone 版（预览）

`ios/` 是原生的 iPhone 版（SwiftUI），判断规则从安卓版逐行移植过来，同样的测试图算出来的清晰度、画面指纹完全一致。目前只在一台 iPhone 14 Pro Max（iOS 18.7）上用真实相册测过。

还没有 App Store、TestFlight 的下载链接，现在只能自己用 Mac 编译安装：

- 需要：一台 Mac，装 Xcode 26（第一次还要在 Xcode → Settings → Components 下载 iOS 组件，约 8 GB）；iPhone 系统 iOS 18 或以上；一个 Apple ID（免费的就行）；能传数据的数据线。
- 步骤：
  1. Xcode → Settings → Accounts 登录 Apple ID。
  2. 打开 `ios/QingleAlbum.xcodeproj`。把 `ios/Signing.example.xcconfig` 复制成 `ios/Signing.xcconfig`，填上自己的 Team ID（或者在 Signing & Capabilities 里选 Team）。这个文件不会提交到 git。
  3. iPhone 用数据线连 Mac，点“信任此电脑”。在 Xcode 里选这台 iPhone，点运行。第一次会提示开发者模式没开：iPhone 上“设置 → 隐私与安全性 → 开发者模式”打开，重启后再运行一次。
  4. 第一次打开提示“未受信任的开发者”时：“设置 → 通用 → VPN与设备管理”里信任自己的 Apple ID。
- 用免费 Apple ID 装的 App 7 天后会打不开，要用 Xcode 再装一次（数据都在）。

和安卓版的不同：
- 删掉的照片在系统“照片”App 的“最近删除”里，App 没法替你清空，只能跳过去。
- iOS 不告诉 App 一张图是哪个 App 存的，所以没有“App 存的图”按来源分，相机照片靠尺寸和比例判断。
- 美感评分用的是 iOS 18 自带的图像美感评估，不是安卓版的 NIMA 模型；文字识别用 iOS 自带的识字。相机照片只识系统认为是“实用类”的（拍的文件、收据、白板）。
- 每月提醒：iOS 不让 App 在后台每天跑，所以是每次整理完预约一条本地通知（离上次提醒满 30 天那天的晚上 8 点，能腾出 500 MB 以上才预约），到点系统自己弹。设置里能关。
- 还没有：充电时后台分析、设置里的各项阈值。
- 开了“iCloud 照片”的，删除会同步删掉 iCloud 和其他设备上的这张。

## 隐私和安全

- **没有联网权限**。可以在手机“设置 → 应用 → 轻了相册 → 权限”里自己确认。人脸检测、文字识别、美感评分用的都是内置在 App 里的离线模型。
- **App 自己删不了照片**。每次删除都会弹出安卓系统的确认框，默认先进“最近删除”，30 天内能恢复。
- **收藏的照片和视频永远不会被建议删除**。
- 证件上识别出的长串号码（身份证号、卡号）在本地也是打了码存的。
- 崩溃和出错只记在手机里。“设置 → 反馈问题”生成的报告只有手机型号、系统版本、照片数量和出错记录，没有照片，也没有文件名，发不发由你决定。

清理前建议先备份重要照片。开了云相册同步的，手机上删除后云端可能也会跟着删。

## 它怎么判断

**哪些算一组相似照片**：拍摄时间挨着（默认 2 分钟内），而且“画面指纹”（缩成很小的黑白图比较明暗走向）和颜色分布都接近。内容完全一样的照片（重复保存、微信转存）不管隔多久都归到一组，留原图。“角度不同”的组还会识字：两页不同的文件字对不上，就不算相似。

**一组里留哪张**：
- 清晰度最重要：先看本身糊不糊，再在取景几乎一样的连拍之间比谁更清楚。
- 曝光：大片死白、死黑扣分。
- 人脸：有没有人闭眼、人数齐不齐。
- 构图美感：离线 AI 审美模型（NIMA）打 1–10 分，在都清楚的照片里挑更好看的。

**废片**：先找画面里最清楚的一小块，看细节够不够。背景虚化（人像模式）只要主体清楚就不算糊；偏暗、雾天的照片会先补偿明暗。只有很确定的才默认勾选。这套阈值用一部手机上 7000 多张真实照片校准过，宁可漏掉一些稍微糊的，也不误伤云、天空、食物这类“画面本来就平滑”的好照片。

**场景精选**：按拍摄时间（和 GPS，如果照片里有）把一次出游切成场景，再兼顾“拍得好”和“画面不重复”挑精华。

**视频**：每个视频在 10%、30%、50%、70%、90% 处各抽一帧，用和照片一样的方法看是不是黑屏、没拍到东西、全程模糊；画面和时长都一样的认定为重复保存。

这些都是规则和小模型的判断，会有错。轻了相册只负责“推荐”，删不删由你决定。

## 从源码构建

需要 JDK 17 和 Android SDK（compileSdk 35）。

```bash
git clone https://github.com/vickysy/qingle-album.git
cd qingle-album
./gradlew :app:assembleRelease
```

- 产物在 `app/build/outputs/apk/release/app-release.apk`。
- 没有 `keystore.properties` 时，release 包会用调试签名，自己装着用没问题。要发布自己的版本，在项目根目录建 `keystore.properties`（`storeFile`、`storePassword`、`keyAlias`、`keyPassword`），这个文件已经在 `.gitignore` 里。
- 跑单元测试：`./gradlew :app:testReleaseUnitTest`

## 项目结构

| 位置 | 内容 |
| --- | --- |
| `app/src/main/java/com/dtu/cleaner/core/` | 判断规则（纯算法，能在电脑上测试）：画面指纹、清晰度、分组、打分、场景、视频、文字分类 |
| `.../analysis/` | 分析流程：解码、人脸检测、美感评分、识字、视频抽帧、后台任务 |
| `.../media/` | 视频压缩（Media3 Transformer）、截图笔记（拼长图、分享） |
| `.../data/` | 读相册（MediaStore）、本地数据库、设置、整理结果 |
| `.../ui/` | 各个界面（Jetpack Compose，仿 iOS 风格） |
| `app/src/test/` | 单元测试 |
| `website/` | 官网（纯静态页面），`deploy/` 是它的 nginx 配置 |
| `ios/` | iPhone 版（SwiftUI）：`Core/` 判断规则（和安卓版同一套），`Data/` 读相册、分析、压缩、拼长图，`UI/` 各个界面 |

## 用到的开源组件

- 界面：Kotlin、Jetpack Compose、Coil
- 美感评分：[idealo/image-quality-assessment](https://github.com/idealo/image-quality-assessment) 的 NIMA 模型（Apache-2.0），LiteRT 版本来自 [litert-community/NIMA-LiteRT](https://huggingface.co/litert-community/NIMA-LiteRT)，用 Google LiteRT 运行
- 人脸检测、中文文字识别、二维码识别：Google ML Kit 离线版（内置模型，不需要 Google 服务；按 [ML Kit 条款](https://developers.google.com/ml-kit/terms) 使用）
- 视频压缩：AndroidX Media3 Transformer
- 后台任务：AndroidX WorkManager
